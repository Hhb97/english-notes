## 怎么学

每一页都由三种卡片组成，工具条控制显示什么：

| 你想做的事 | 怎么操作 |
| --- | --- |
| 直接看英文和中文 | 默认状态：英文、音标、中文都显示，点喇叭就能听 |
| 只记英文，不依赖中文 | 切到「英文优先」模式，中文会遮住；右侧 **中** 也能单独控制某一条 |
| 自己先想英文 | 切到「自测」模式，英文和音标会遮住，点模糊文字就能看 |
| 只练听力 | 关掉「英文」和「中文」，只点喇叭 |
| 听标准发音 | 点喇叭按钮；工具条可调语速、换声音（Edge 浏览器有很自然的在线语音） |
| 整段跟读对话 | 对话卡片右上角点「播放整段对话」，两位说话人用不同声音 |

## 练一遍再走

每篇笔记底部都有三级练习：**能认出**（看中文选英文）、**能回忆**（补全挖空的英文）、**能使用**（自己写一句，再对照参考）。先作答再看反馈，答得不好的会按 1/3/7/14/30 天间隔回到首页的「今日复习」。掌握状态只保存在当前浏览器。

## 学习路线

想补生活口语，先看「日常生活」「人际社交」「出行旅行」「健康生活」；想系统积累词汇，按「主题词汇」一页页过——生活高频词打底，再进「职场核心词」「职场场景词」，目标是攒够日常工作沟通需要的量。工作场景看「职场沟通」，IT 从业者再看「IT 英语」。想说得更得体，最后用「深入进阶」。

## 三个建议

- **先开口，再追求准确。** 对方能听懂就达到目的，别等把语法学完才说。
- **整句背，不要拆词背。** 本站收的都是能直接拿来用的整句，把它们当模板，替换里面的名词就行。
- **每天 15 分钟，比周末集中两小时有效。** 选一页，遮住英文，看中文说一遍，再点开核对并跟读。
