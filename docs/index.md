## 怎么学

每一页都由三种卡片组成，顶部的工具条控制显示什么：

| 你想做的事 | 怎么操作 |
| --- | --- |
| 看中文，自己先想英文 | 默认状态：英文和音标是模糊的，点右侧的 **EN** 按钮，或直接点模糊的文字，就会显示 |
| 一次看全部英文 | 工具条里打开「英文」 |
| 只练听力 | 关掉「英文」和「中文」，只点喇叭 |
| 听标准发音 | 点喇叭按钮；工具条可调语速、换声音（Edge 浏览器有很自然的在线语音） |
| 整段跟读对话 | 对话卡片右上角点「播放整段对话」，两位说话人用不同声音 |

## 学习路线

先把「入门基础」的音标和 IT 词汇读法过一遍，再按你的工作场景挑「职场沟通」或「IT 词汇与场景」里的页面，最后用「深入进阶」把话说得更得体。

## 三个建议

- **先开口，再追求准确。** 同事能听懂就达到目的，别等把语法学完才说。
- **整句背，不要拆词背。** 本站收的都是能直接拿来用的整句，把它们当模板，替换里面的名词就行。
- **每天 15 分钟，比周末集中两小时有效。** 选一页，遮住英文，看中文说一遍，再点开核对并跟读。
