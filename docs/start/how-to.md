# 先看这里：怎么用这个站学英语

> [!ABSTRACT]
> - 每条词句都有三样东西：**英文**、**音标**、**中文**，右侧有**喇叭**（听发音）和 **中**（显示 / 隐藏这一条的中文）。
> - 页面顶部的工具条能一次性控制：显示模式、英文、音标、中文，朗读的语速和声音。
> - 进入页面默认显示英文，想自测时切到「自测」模式，英文和音标会遮住。

## 一、三种卡片

### 1. 词句卡：一句话一张卡

先看英文，点喇叭听标准发音，跟读两遍；再看中文核对理解。想练「看英文回忆意思」就点 **中** 把中文遮住。

```phrases
Could you say that again, please? | /kʊd juː seɪ ðæt əˈɡen pliːz/ | 能请你再说一遍吗？
I'm a backend developer. | /aɪm ə ˈbækend dɪˈveləpər/ | 我是做后端开发的。 | backend 重音在第一个音节：BACK-end
It works on my machine. | /ɪt wɜːrks ɑːn maɪ məˈʃiːn/ | 在我机器上是好的。 | 程序员的经典自嘲
```

### 2. 单词卡：单词 + 例句

单词下面跟一个真实生活或工作场景的例句，例句也有自己的喇叭。

```words
deploy | /dɪˈplɔɪ/ | v. 部署，上线 | We deploy to production every Friday. | /wiː dɪˈplɔɪ tuː prəˈdʌkʃən ˈevəri ˈfraɪdi/ | 我们每周五部署到生产环境。
latency | /ˈleɪtənsi/ | n. 延迟 | The API latency is under two hundred milliseconds. | /ðə ˌeɪˌpiːˈaɪ ˈleɪtənsi ɪz ˈʌndər tuː ˈhʌndrəd ˈmɪlɪˌsekəndz/ | 这个接口的延迟低于两百毫秒。
```

### 3. 对话卡：一段完整的情景

对话用左右气泡显示。点右上角「播放整段对话」，两位说话人会用不同的声音依次朗读，适合跟读和练听力。

```dialog
title: 站会上被问到进度
Lead: How's the login feature going? | /haʊz ðə ˈlɔːˌɡɪn ˈfiːtʃər ˈɡoʊɪŋ/ | 登录功能进展怎么样？
Dev: I finished the API yesterday. Today I'm working on the tests. | /aɪ ˈfɪnɪʃt ðə ˌeɪˌpiːˈaɪ ˈjestərˌdeɪ təˈdeɪ aɪm ˈwɜːrkɪŋ ɑːn ðə tests/ | 接口昨天写完了，今天在写测试。
Lead: Any blockers? | /ˈeni ˈblɑːkərz/ | 有阻塞吗？
Dev: No blockers right now. | /noʊ ˈblɑːkərz raɪt naʊ/ | 目前没有。
```

## 二、工具条

| 按钮 | 作用 |
| --- | --- |
| 默认英文 / 自测 | 一键切换模式：自测会遮住英文和音标 |
| 英文 | 一次显示或遮住全部英文 |
| 音标 | 单独隐藏音标，只看英文 |
| 中文 | 遮住中文，练「看英文回忆意思」和听力 |
| 语速 | 慢 / 正常 / 快，听不清就调慢 |
| 声音 | 选择朗读的声音；Edge 浏览器里带 Natural 的声音最自然 |

你的选择会保存在浏览器里，下次打开还是这样。

> [!TIP] 朗读用的是浏览器自带的语音
> 不需要联网下载音频。Windows 上推荐用 **Edge**，声音最自然；Chrome 也可以；如果完全没有声音，检查系统是否安装了英文语音。

## 三、每天 15 分钟的练习办法

1. **看中文说英文（5 分钟）**：挑一页，切到自测模式，逐条看中文，开口说，再点模糊的英文核对。
2. **跟读（5 分钟）**：点喇叭听一遍，暂停后自己读一遍，注意重音符号 ˈ 后面的音节要读重。
3. **替换练习（5 分钟）**：把句子里的名词换成你自己的项目、同事、系统，大声说出来。

> [!QUESTION] 想检验自己：怎么用英文问“你能再说慢一点吗？”
> 点开答案前先自己说一遍。
>
> ```phrases
> Could you speak a little more slowly, please? | /kʊd juː spiːk ə ˈlɪtəl mɔːr ˈsloʊli pliːz/ | 能请你说慢一点吗？
> ```
